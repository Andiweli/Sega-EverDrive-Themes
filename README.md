## 🕹️ How to use these themes (Mega EverDrive Pro)

Requirements:

- **Mega EverDrive Pro** flash cartridge  
- Mega Drive / Genesis console (or compatible)  
- Firmware **MEGAOS 4.07 or higher** (required for theme support)

### Installation steps

1. **Copy the .BGR file(s)**  
   - Place one or more `.bgr` files onto your EverDrive SD card.  
   - You can put them in any folder you like (for example `MEGA/THEMES` or `THEMES`).

2. **Enable themes in the Mega EverDrive Pro menu**  
   - Boot your Mega Drive / Genesis with the EverDrive inserted.  
   - Open the EverDrive **Options / Menu settings** and make sure **Themes** are enabled.

3. **Select and set the theme**  
   - In the file browser of the EverDrive Pro, navigate to the `.bgr` file (e.g. `console.bgr`).  
   - Highlight the file and press **A** on the controller.  
   - Choose **“Set theme”** and confirm.

After that, the selected `.bgr` file becomes the **active menu theme** and will be used every time the EverDrive menu is shown (until you change it again).

## ❓ What is a .BGR theme?

The Mega EverDrive Pro supports **custom menu themes** in a special **`.bgr` format**:

- Contains background graphics and animation frames  
- Used by the cartridge’s menu to draw its UI background  
- Allows static images, horizontal / vertical scrolling and more (depending on theme design)

All themes in this repo are already compiled as `.bgr` and **ready to use**.
